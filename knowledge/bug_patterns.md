# Common logic bugs (all languages)
- Off-by-one errors in loops and slicing; wrong comparison operator.
- Null / None / nil dereference, unchecked return values and error codes.
- Division by zero, unhandled empty collections.
- Resource leaks: unclosed files, sockets, memory never freed.
- Assignment used where comparison was intended; unreachable code; dead branches.
- Shadowed variables, mutable default state shared across calls.
- Integer truncation and signed/unsigned mixups.
- Infinite loops and missing termination conditions; recursion without a base case.
